## 1. 예선 구현 기능

### F-01. 항공·철도 예매정보 입력

- **설명:** 사용자가 항공편과 열차 예매정보를 입력해 타임라인 생성에 활용한다.
- **사용자 입력:** 자유 텍스트
- **처리 내용:** 입력값을 검증하고 항공편·열차·날짜·시간 정보를 구조화한다.
- **출력 결과:** 구조화된 항공·철도 예매정보 데이터
- **기능 로직 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-02. 여행 유형·동행 조건 선택

- **설명:** 사용자의 동행자 특성을 선택한다.
- **사용자 입력:** 동행 조건 선택 폼
- **처리 내용:** 선택값을 관광지 추천과 타임라인 생성에 사용할 조건 데이터로 변환한다.
- **출력 결과:** 동행 조건 데이터
- **추천 기준 담당:** 준영
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-03. 관광지 후보 추천

- **설명:** 여행 지역과 동행 조건을 바탕으로 적합한 관광지 후보를 여러 개 추천한다.
- **입력 데이터:** 여행 지역, 동행 조건, 이전에 노출된 관광지 목록
- **처리 내용:** 동행 조건에 적합한 관광지를 필터링하고 추천 이유와 체류시간을 함께 제공한다.
- **출력 결과:** 관광지 후보 목록, 추천 이유, 예상 체류시간, 태그
- **추천 기준 담당:** 준영
- **백엔드 연결 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-04. 관광지 선택 방식 결정

- **설명:** 사용자가 관광지를 직접 선택하거나 AI 자동 선택 방식을 선택한다.
- **사용자 입력:** 직접 선택한 관광지 또는 AI 자동 선택 요청
- **처리 내용:** 직접 선택 시 선택된 장소를 저장하고, 자동 선택 시 조건에 맞는 관광지 조합을 결정한다.
- **출력 결과:** 최종 관광지 목록과 선택 방식
- **기능 로직 담당:** 여진
- **추천 기준 지원:** 준영
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-05. 다른 관광지 추천받기

- **설명:** 기존 관광지 후보가 마음에 들지 않을 경우 새로운 후보를 추천한다.
- **사용자 입력:** 이전에 노출된 관광지 목록, 현재 선택한 관광지
- **처리 내용:** 선택한 장소는 유지하고, 선택하지 않은 기존 후보를 제외한 새로운 관광지를 추천한다.
- **출력 결과:** 새 관광지 후보 목록
- **추천 로직 담당:** 준영
- **백엔드 연결 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-06. 맞춤 타임라인 생성

- **설명:** 항공·철도 일정과 최종 선택된 관광지를 반영해 실행 가능한 여행 타임라인을 생성한다.
- **입력 데이터:** 구조화된 예매정보, 동행 조건, 관광지 선택 방식, 최종 관광지 목록
- **처리 내용:** 교통 일정은 고정하고 관광지 운영시간·이동시간·체류시간·휴식시간을 고려해 관광지를 시간순으로 배치한다.
- **출력 결과:** 시간대별 이동·관광 일정 및 장소별 배치 이유
- **기능 로직 담당:** 여진
- **추천 기준 지원:** 준영
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-07. 다이어리 자료 입력

- **설명:** 여행 다이어리 생성에 필요한 사진과 짧은 메모를 입력받는다.
- **사용자 입력:** 여행 사진, 장소별 메모, 원하는 문체 및 분량
- **처리 내용:** 입력된 사진과 메모를 여행 일정 또는 방문 장소와 연결한다.
- **출력 결과:** 다이어리 생성용 입력 데이터
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-08. AI 여행 다이어리 생성

- **설명:** 여행 타임라인과 사진·메모를 바탕으로 여행 다이어리와 SNS용 콘텐츠를 생성한다.
- **입력 데이터:** 여행 타임라인, 사진, 짧은 메모, 문체 및 분량
- **처리 내용:** 입력 자료를 바탕으로 여행 내용을 요약하고 여행기와 SNS용 문구를 생성한다.
- **출력 결과:** 여행 다이어리, SNS 문구, 사진 캡션 및 해시태그
- **기능 로직 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** O

---

### F-09. 타임라인 재생성

- **설명:** 사용자의 수정 요청이나 변경 조건을 반영해 기존 타임라인을 다시 생성한다.
- **사용자 입력:** 특정 장소 제외, 일정 강도 변경, 실내 중심 등 수정 요청
- **처리 내용:** 기존 타임라인과 수정 요청을 함께 전달해 새로운 타임라인을 생성한다.
- **출력 결과:** 수정된 여행 타임라인
- **기능 로직 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** 선택 구현

---

### F-10. 다이어리 재생성

- **설명:** 사용자의 요청에 따라 다이어리의 문체, 분량 또는 형식을 변경한다.
- **사용자 입력:** 문체 변경, 분량 조절, SNS용 형식 등 수정 요청
- **처리 내용:** 기존 다이어리와 수정 요청을 반영해 새로운 결과를 생성한다.
- **출력 결과:** 수정된 여행 다이어리 또는 SNS 콘텐츠
- **기능 로직 담당:** 여진
- **화면 구현 담당:** 서영
- **예선 구현:** 선택 구현

## 2. 프로토타입 화면 흐름

```
메인 화면
→ 예매정보 입력 화면
→ 동행 조건 선택 화면
→ 관광지 추천·선택 화면
→ 맞춤 타임라인 결과 화면
→ 여행 다이어리 자료 입력 화면
→ 다이어리 결과 화면
```

---

## 3. 프로토타입 핵심 화면

### S-01. 메인 화면

- 서비스 소개
- 핵심 기능 요약
- 여행 만들기 버튼
- **화면 담당:** 서영

---

### S-02. 예매정보 입력 화면

- 항공편 예매정보 입력
- 철도 예매정보 입력
- 여행 시작일·종료일 입력
- 다음 단계 이동 버튼
- **화면 담당:** 서영
- **입력 처리 담당:** 여진

---

### S-03. 여행 유형·동행 조건 선택 화면

- 혼자·친구·연인·유아·고령자·교통약자·반려동물 동반 조건 선택
- 관광지 추천받기 버튼
- **화면 담당:** 서영
- **추천 기준 담당:** 준영

---

### S-04. 관광지 추천·선택 화면

- 추천 관광지 카드 목록
- 대표 이미지
- 관광지 설명
- 동행 조건에 적합한 추천 이유
- 예상 체류시간
- 편의시설 및 특징 태그
- 관광지 다중 선택
- 선택한 관광지 개수 표시
- 다른 장소 추천받기 버튼
- 선택한 장소로 일정 만들기 버튼
- AI 추천대로 떠나기 버튼
- **화면 담당:** 서영
- **추천 기준 담당:** 준영
- **백엔드 연결 담당:** 여진

---

### S-05. 맞춤 타임라인 결과 화면

- 시간대별 이동 및 관광 일정
- 장소별 추천 이유
- 교통 일정과 관광 일정 구분 표시
- 다이어리 만들기 버튼
- 타임라인 재생성 버튼 *(선택 구현)*
- **화면 담당:** 서영
- **생성 로직 담당:** 여진

---

### S-06. 여행 다이어리 자료 입력 화면

- 여행 사진 업로드
- 장소별 짧은 메모 입력
- 다이어리 문체 선택
- 다이어리 분량 선택
- 다이어리 생성 버튼
- **화면 담당:** 서영

---

### S-07. 다이어리 결과 화면

- 날짜별 여행 일기
- 여행 전체 요약
- SNS용 문구
- 사진 캡션
- 해시태그
- 결과 편집 또는 재생성 버튼 *(선택 구현)*
- **화면 담당:** 서영
- **생성 로직 담당:** 여진
