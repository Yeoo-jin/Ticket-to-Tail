## 1. 서비스 개요

항공·철도 예매정보와 동행 조건을 기반으로 사용자에게 적합한 관광지 후보를 추천하고, 사용자가 직접 선택하거나 AI에게 선택을 맡길 수 있도록 한다. 이후 선택된 관광지와 교통 일정을 바탕으로 실행 가능한 맞춤형 여행 타임라인을 생성하고, 여행 후에는 일정과 사진·메모를 활용해 AI 여행 다이어리를 만들어주는 서비스이다.

예선 프로토타입에서는 항공권·승차권 이미지 인식이나 실시간 교통 API 연동보다, 예매정보 텍스트 분석, 동행 조건 기반 관광지 추천, 타임라인 생성, AI 다이어리 생성이라는 핵심 흐름을 우선 구현한다.

---

## 2. 문제 정의

> 항공·철도·관광 정보가 여러 서비스에 분산되어 있어 사용자가 실제 예약 시간을 기준으로 여행 일정을 직접 조정해야 한다. 특히 유아, 고령자, 교통약자, 반려동물 동반 여행은 이동시간과 이용 가능 시설을 추가로 고려해야 해 일정 수립 부담이 크다. 또한 여행 후 사진과 이동 기록을 따로 정리해야 해 여행 경험이 기록과 지역 관광 홍보로 자연스럽게 이어지기 어렵다.
> 

---

## 3. 서비스 핵심 가치

- 실제 항공·철도 예약시간을 기준으로 실행 가능한 일정 생성
- 동행 조건을 반영한 맞춤형 관광 추천
- 여행 전 일정 생성부터 여행 후 기록까지 하나의 흐름으로 연결
- 생성된 다이어리를 편집·공유해 지역 관광 콘텐츠로 확장

---

## 4. 핵심 사용자 흐름

```
항공·철도 예매정보 텍스트 입력
→ 동행 조건 선택
→ 동행 조건에 적합한 관광지 후보 추천
→ 관광지 직접 선택 또는 AI 추천대로 선택
→ 필요 시 다른 관광지 후보 다시 추천
→ 선택된 관광지를 기반으로 AI 맞춤 타임라인 생성
→ 여행 사진·메모 입력
→ AI 여행 다이어리 생성
→ 결과 편집·공유 <본선 확장>
→ 타임라인·다이어리 재생성 <선택 구현>
```

## 5. 예선 구현 범위

**필수 구현**

- 항공·철도 예매정보 텍스트 입력 및 구조화
- 동행 조건 선택
- 동행 조건 기반 관광지 후보 추천
- 관광지 직접 선택
- AI 추천대로 관광지 자동 선택
- 다른 관광지 후보 다시 추천
- 선택된 관광지 기반 맞춤 타임라인 생성
- 사진·메모 기반 AI 여행 다이어리 생성

**가능하면** 구현

- 타임라인 재생성
- 다이어리 재생성
- 결과 일부 편집

**본선 확장**

- 항공권·승차권 OCR
- 실제 관광 공공데이터 연동 및 추천 범위 확대
- 실시간 항공편·열차 지연 정보 연동
- 지연·변경 시 타임라인 자동 재구성
- 공동 편집 및 공유
- 사용자 계정·여행 기록 저장
- 위치 기반 알림

### 5.1 항공·철도 예매 정보 입력

사용자가 항공편과 열차 예매 정보를 텍스트로 직접 입력한다.

**입력 정보 예시**

- 항공편 출발지·도착지
- 항공편 출발·도착 일시
- 열차 출발역·도착역
- 열차 출발·도착 일시
- 여행 시작일·종료일

**예시**

```
8월 12일 오전 10시 30분 인천공항 도착
8월 12일 오후 1시 20분 서울역 출발
오후 4시 5분 부산역 도착
8월 14일 오후 6시 인천공항 출발
```

예선에서는 자유로운 텍스트 입력을 받은 뒤 AI가 필요한 항목을 추출하는 방식으로 구현한다.

---

### 5.2 여행 유형 및 동행 조건 선택

사용자는 함께 여행하는 동행자의 특성을 선택한다.

**동행 조건 예시**

- 혼자 여행
- 친구·연인 동반
- 유아 동반
- 고령자 동반
- 교통약자 동반
- 반려동물 동반

선택된 조건은 관광지 적합성, 이동 거리, 휴식 간격, 편의시설 및 추천 이유에 반영한다.

---

### 5.3 관광지 추천 및 선택

예매정보에서 확인한 여행 지역과 사용자가 선택한 동행 조건을 바탕으로 적합한 관광지 후보를 여러 개 추천한다.

**관광지 카드 제공 정보**

- 관광지명
- 대표 이미지
- 한 줄 설명
- 동행 조건에 적합한 이유
- 예상 체류시간
- 편의시설 및 특징 태그

사용자는 다음 두 가지 방식 중 하나를 선택할 수 있다.

#### 직접 선택하기

추천된 관광지 중 방문하고 싶은 장소를 여러 개 선택한다. 추천된 후보가 마음에 들지 않을 경우, 선택한 관광지는 유지한 채 나머지 후보를 새로 추천받을 수 있다.

#### AI 추천대로 떠나기

사용자가 관광지를 직접 고르지 않고, AI가 동행 조건·이동시간·운영시간을 고려해 적합한 장소를 자동으로 선택한다.

AI 자동 선택은 완전한 무작위가 아니라, 조건을 충족하는 관광지 후보 안에서 다양한 조합을 제안하는 방식으로 동작한다.

---

### 5.4 AI 맞춤 여행 타임라인 생성

입력된 항공·철도 일정, 동행 조건, 사용자가 직접 선택하거나 AI가 선택한 관광지를 바탕으로 실제 이동 가능한 여행 타임라인을 생성한다.

**반영 요소**

- 항공편 및 열차 출발·도착 시각
- 공항·역·관광지 사이 이동시간
- 사용자가 선택한 관광지
- 관광지 운영시간
- 관광지별 예상 체류시간
- 식사 및 휴식시간
- 동행자별 이동 제약 조건

**출력 예시**

```
10:30 인천공항 도착
11:30 입국 및 수하물 수령 완료 예상
11:50 공항철도 탑승
12:50 서울역 도착 및 점심
13:20 KTX 탑승
16:05 부산역 도착
16:40 숙소 체크인 및 휴식
18:00 자갈치시장 방문
19:30 광안리 야경 관람
```

각 장소에는 추천 이유를 함께 제공한다.

```
유아 동반 여행이므로 이동거리가 짧고 휴식 공간이 있는 장소를 우선 추천했습니다.
```

---

### 5.5 AI 여행 다이어리 생성

생성된 여행 타임라인과 사용자가 입력한 사진·짧은 메모를 바탕으로 여행 다이어리를 생성한다.

**입력 정보**

- 생성된 여행 타임라인
- 방문 장소
- 여행 사진
- 장소별 짧은 메모
- 원하는 문체 또는 분위기

**출력 형태**

- 날짜별 여행 일기
- 여행 전체 요약
- SNS 게시글 문구
- 사진별 캡션
- 해시태그

**예시**

```
인천공항에 도착한 뒤 공항철도를 타고 서울역으로 이동했다.
KTX를 타고 부산에 도착한 후 자갈치시장에서 부산의 첫 저녁을 보냈다.
짧은 일정이었지만 바다와 지역 음식을 함께 즐길 수 있어 알찬 하루였다.

#부산여행 #KTX여행 #자갈치시장 #국내여행
```

### 5.6 재생성 기능

개발 시간이 허용될 경우 타임라인 또는 다이어리 결과를 다시 생성할 수 있도록 한다.

**재생성 방식 예시**

- 전체 결과 다시 생성
- 특정 일정만 변경
- 여행 유형 변경 후 다시 생성
- 더 여유로운 일정으로 변경
- 실내 관광지 중심으로 변경
- 다이어리 문체 변경
- SNS용 짧은 글로 변경

예선에서는 실제 지연 정보 자동 감지보다, 사용자가 수정 요청을 입력하면 결과를 다시 생성하는 방식으로 구현한다.

## 6. 차별점

> 
> 
> 
> 기존 여행 추천 서비스가 사용자의 취향이나 희망 지역을 바탕으로 관광지를 일괄 추천하는 데 그치는 경우가 많다면, 본 서비스는 이미 예약된 항공·철도 시간을 기준으로 실제 방문 가능한 관광지 후보를 제공한다.
> 
> 사용자는 추천된 장소를 직접 선택해 여행 의도를 반영할 수도 있고, 선택의 부담을 줄이기 위해 AI에게 관광지 선택을 맡길 수도 있다. 또한 추천 결과가 마음에 들지 않을 경우 기존 선택을 유지한 채 새로운 후보를 다시 추천받을 수 있다.
> 
> 최종적으로 선택된 장소를 항공·철도 일정 사이에 배치해 실행 가능한 타임라인을 생성하고, 여행 후에는 동일한 일정 데이터를 여행 다이어리와 SNS 콘텐츠로 연결한다.
>

## 7. 예선 데모 시나리오

### 사용자 조건

- 인천공항 입국 후 부산 여행
- 항공편과 KTX 예약 완료
- 유아 동반
- 이동이 짧고 여유로운 관광 선호

### 데모 흐름

```
항공·철도 예매정보 텍스트 입력
→ 유아 동반 조건 선택
→ 유아 편의시설과 짧은 이동거리를 고려한 부산 관광지 6곳 추천
→ 추천 장소 중 2곳 직접 선택
→ 나머지 후보가 마음에 들지 않아 ‘다른 장소 추천받기’ 실행
→ 새롭게 추천된 장소 중 1곳 추가 선택
→ 선택한 관광지와 교통 일정을 반영한 타임라인 생성
→ 여행 사진과 메모 입력
→ 날짜별 AI 다이어리와 SNS 게시물 생성
```

## 8. 프로토타입 목표

예선 프로토타입의 목표는 모든 기능을 완성하는 것이 아니라, 다음 핵심 가치를 작동하는 화면으로 보여주는 것이다.

> 항공·철도 예매정보와 동행 조건을 한 번 입력하면 적합한 관광지를 추천받고, 사용자가 원하는 장소를 직접 선택하거나 AI에게 선택을 맡길 수 있다. 이후 선택된 장소를 실제 교통 일정 사이에 배치해 실행 가능한 여행 타임라인을 생성하고, 여행 후에는 해당 여정을 자동으로 다이어리와 SNS 콘텐츠로 완성한다.
> 

본선 진출 시 실제 항공·철도 데이터와 관광 공공데이터를 연동하고, 지연·변경 상황에 따른 자동 일정 재구성 기능을 추가한다.
